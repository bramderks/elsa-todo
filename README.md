# Elsa's checklist 🌸

Een vrolijke dagelijkse checklist voor Elsa, gebouwd met Next.js en Neon Postgres.

## Lokaal starten

```bash
npm install
npm run dev
```

Stel `DATABASE_URL` in op een Neon Postgres connection string. De app bewaart de checklist centraal zodat dezelfde voortgang op meerdere apparaten zichtbaar is.
